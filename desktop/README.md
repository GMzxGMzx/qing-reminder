# 轻提醒 · Windows 桌面版

透明、置顶、可拖拽的悬浮小窗提醒工具。到点后在屏幕中央弹出提醒，必须手动确认才进入下一轮，适合长期挂在桌面上管理周期性事项。

## 下载安装

从 [Releases](https://github.com/GMzxGMzx/qing-reminder/releases) 下载：

- `qing-reminder-setup-1.0.0.exe`：安装包，双击安装。
- `qing-reminder-portable-1.0.0.zip`：免安装版，解压后双击 `轻提醒.exe` 即可，无需安装权限。

> **未签名应用提示**：安装包未进行代码签名，Windows 11 的「智能应用控制」可能会拦截。可在「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制」中关闭该防护后重试。关闭后无法重新开启，请自行确认可接受。

## 功能一览

- **悬浮小窗**：透明毛玻璃、始终置顶、可拖拽；展示最近 5 个提醒的实时倒计时，每行可单独「立即完成」。
- **展开管理窗**：添加、暂停/继续、立即完成、删除提醒，查看统计与完成历史。
- **到点弹窗**：移动到屏幕中央，使用不透明背景；显示文字与图片备注，并可播放提示音。
- **确认机制**：必须点击「确认完成」才记录一次并进入下一轮；也可延后 5/15 分钟，或结束归档该提醒。
- **备注**：文字备注可换行，悬浮时显示；图片备注自动压缩为最长边 720px 的 JPEG，避免占用过多空间。
- **全局生效时间**：设置整体生效区间；范围外不触发提醒，并显示「未到开始时间 / 已过结束时间」。
- **记录与统计**：显示进行中、今日完成、累计完成；历史记录倒序展示最近 40 条，可清空。
- **窗口设置**：透明度滑块、置顶开关、系统托盘、显示/隐藏；已移除位置锁定，标题栏始终可拖拽。
- **稳定倒计时**：由 Electron 主进程定时驱动，窗口失焦、切到后台后仍持续刷新。

## 使用流程

1. 点击标题栏「▢」展开，填写事件名称与间隔分钟数（1～10080 分钟），可选填写备注和图片。
2. 小窗实时显示最近的倒计时；也可在列表中暂停或立即完成。
3. 到点后弹窗居中出现，查看备注后点击「确认完成」或选择延后。
4. 在展开窗查看统计、历史，并设置全局生效时间、透明度与置顶。

## 从源码运行

```bash
npm install
npm start
```

启动器 `start.js` 会清除 `ELECTRON_RUN_AS_NODE` 环境变量，避免 Electron 以纯 Node 模式启动导致界面失效。

## 自行打包

```bash
npm run dist
```

产物位于 `dist/轻提醒 Setup 1.0.0.exe`。若 Electron 二进制下载失败，可设置国内镜像：

```bash
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
```

## 数据

数据保存在本机 `localStorage`（key：`qing-reminder-desktop-v1`），不上传服务器，也不需要账号。清除应用数据会同时清除提醒、设置和历史。
