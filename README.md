# 轻提醒

电脑端周期提醒工具。设置事件和提醒间隔，到点弹窗提醒，**必须手动确认完成**才会进入下一轮，并自动记录每次完成的历史。

## 使用

直接用浏览器打开 `index.html` 即可，无需安装依赖或启动服务。

## 功能

- 自定义事件名称与提醒间隔（1 分钟 ~ 7 天），提供常用快捷间隔
- 实时倒计时，显示下次提醒时间；支持暂停/继续、删除、归档恢复
- 到点弹窗 + 提示音 + 系统通知，标题栏闪烁提醒
- 手动点击「确认完成」后才记录历史并开始下一轮；也可延后 5/15 分钟
- 完成历史按时间倒序展示，支持按事件筛选和清空
- 今日完成、累计完成和进行中数量统计

## 数据存储

所有数据保存在本机浏览器的 `localStorage`（key: `qing-reminder-v1`），不会上传到任何服务器。请保持页面打开以获得准时提醒；若关闭期间有提醒到期，重新打开时会立即弹出待确认窗口。

## 技术

纯原生 HTML / CSS / JavaScript，单文件应用，零依赖。
